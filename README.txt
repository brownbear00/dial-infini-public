DIAL INFINI
============

This is a React site. The pages, images, and styles are the same as the previous PHP site.

LOCAL
1. npm install
2. npm run dev
3. Open http://127.0.0.1:5173/

RENDER
The Dockerfile builds the site and serves it. Set the service to use Docker.
Render sets PORT automatically.

PAGES
Home, Features, Pricing, About, Contact, Privacy, Terms.
Content lives in src/data/site.json.
Images stay in /uploads. Styles stay in /assets/css.
